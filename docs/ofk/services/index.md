# Services

Consumer-facing service concepts. The container they run in is documented in [LXC Containers](../lxc/index.md); Mini-PC-hosted services in [Mini PC CasaOS](../infrastructure/minipc-casaos.md).

* [Traefik (Mini PC)](traefik-minipc.md) - Reverse proxy + Cloudflare Tunnel ingress for all public subdomains
* [LiteLLM Router](litellm.md) - Single OpenAI-compatible endpoint, approved catalog 2026-11-09
* [Dados Data Layer](dados.md) - Postgres/Redis/FalkorDB connection reference
* [Xereta](xereta.md) - Knowledge review application (own repo, migrating to Dokploy)
* [Dockhand](dockhand.md) - Docker container management UI + Hawser agents
* [Uptime Kuma](uptime-kuma.md) - Service monitoring (public + LAN)
* [Homepage](homepage.md) - Central dashboard
